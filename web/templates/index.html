1. Vérifier le support

          
La détection est en lecture seule. Une clé dont la partition est montée apparaît en ambre : l'interface peut la démonter avec udisksctl, sans sudo. Les disques système ou participants à un volume LVM/RAID restent refusés.

3. Copier et exécuter dans un terminal

          
Le web ne lance rien. Ouvrez un terminal, collez les commandes dans l'ordre et lisez les confirmations demandées par les scripts.

          

          

          

          

        


        

          
 Pourquoi le web n'exécute pas les commandes

          
Les scripts USB demandent des confirmations destructives, une phrase de passe LUKS2, une phrase age et parfois une interaction avec CUPS. Les exécuter via un serveur web imposerait de transmettre ces secrets au navigateur ou de créer un helper privilégié.

          
Le mode guidé conserve donc la sécurité du terminal : vous vérifiez le disque, vous collez la commande, et les scripts gardent la main sur les confirmations et l'effacement.
